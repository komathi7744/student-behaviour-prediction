Student Behaviour Prediction using Machine Learning

## Objective
This project predicts a student's behaviour (Good, Average, or Bad) 
based on their marks and attendance using a Machine Learning model.

## Dataset
- 20 student records
- Features: Marks, Attendance
- Target: Behaviour (Good/Average/Bad)

## Tools Used
- Python
- Pandas
- Scikit-learn (Decision Tree Classifier)
- Google Colab

## Steps Followed
1. Data loading and cleaning
2. Feature preprocessing (label encoding, removing % symbols)
3. Train-test split
4. Model training using Decision Tree Classifier
5. Model evaluation

## Result
Achieved 75% accuracy on the test dataset.
